AI-Powered Content Security Risk Analysis

Protect your organization from security risks with intelligent AI analysis that identifies potential PII disclosure, credential exposure, and other sensitive information leaks in your content before publication.

You need Content Security Audit if

  • Your organization publishes sensitive content that must comply with privacy regulations
  • You need to prevent accidental disclosure of PII, credentials, or proprietary information
  • Your content workflow requires security risk assessment before publication
  • You want automated detection of potential data leaks in large content volumes

Advanced Security Analysis

  • Configurable Security Vectors

    Flexible security vector management through admin UI with customizable risk scoring from 0 (no risk) to 100 (high risk).

  • Pre-Configured Risk Detection

    Built-in security vectors for common vulnerability patterns:

    • PII Disclosure - Identifies potential exposure of personally identifiable information
    • Credentials Disclosure - Detects API keys, passwords, and authentication data exposure
  • Custom Security Vectors

    Add and delete custom security vectors tailored to your organization's specific security policies and compliance requirements.

  • Intelligent Batch Processing

    Comprehensive batch analysis capabilities with per-vector processing for focused security audits of existing content.

  • Visual Risk Assessment

    Intuitive risk indicators and reporting dashboards provide quick security status overview with detailed findings.

Security Setup Guide

  1. Configure AI provider settings at /admin/config/ai/providers
  2. Manage security vectors at /admin/config/analyze/content-security-audit
  3. Enable/disable the analyzer per content type at /admin/config/content/analyze-settings
  4. Configure permissions at /admin/people/permissions#module-analyze_ai_content_security_audit
  5. Access security audit through the Analyze tab on content
  6. Run batch security analysis at /admin/config/analyze/content-security-audit/batch
