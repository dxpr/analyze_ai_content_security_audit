The AI Content Security Audit is part of the AI module ecosystem. It provides AI-powered security analysis for Drupal content, identifying potential security risks such as PII disclosure, credentials exposure, and other sensitive information leaks.

Features

  • Security vector analysis:
    • Configurable security vectors through admin UI
    • Risk scoring from 0 (no risk) to 100 (high risk)
    • Add/delete custom security vectors
  • Pre-configured security vectors:
    • PII Disclosure - Identifies potential disclosure of personally identifiable information
    • Credentials Disclosure - Detects exposure of API keys, passwords, or authentication data
  • Batch security analysis for existing content
  • Per-vector batch processing for focused analysis
  • Visual risk indicators for quick assessment
  • Integration with the Analyze framework
  • Views integration for security reporting and dashboards

Post-installation

  1. Configure AI provider settings at /admin/config/ai/providers
  2. Manage security vectors at /admin/config/analyze/content-security-audit
  3. Enable/disable the analyzer per content type at /admin/config/content/analyze-settings
  4. Configure permissions at /admin/people/permissions#module-analyze_ai_content_security_audit
  5. Access security audit through the Analyze tab on content
  6. Run batch security analysis at /admin/config/analyze/content-security-audit/batch

Additional requirements

This module requires:

  • Analyze module
  • AI module with a configured provider
  • Views Color Scales module (provides colored tables for report page)
